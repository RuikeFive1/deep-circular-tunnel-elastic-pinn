# 方法说明

## 1. 问题定义

计算域为四分之一圆环

```text
a <= sqrt(x^2 + y^2) <= R,  x >= 0, y >= 0,
a = 1 m, R = 3 m.
```

初始静水应力为 `-p0 I`，其中 `p0 = 10 MPa`；弹性阶段洞壁压力为 `P = 8 MPa`。训练代码内部采用拉应力为正，因此内外圆边界目标法向应力分别为 `-P` 与 `-p0`。

## 2. 网络表示

网络以 `(x, y)` 为输入，直接输出

```text
(ux, uy, sigma_xx, sigma_yy, sigma_zz, sigma_xy).
```

这是位移和应力混合输出。位移的一阶自动微分给出小应变，应力的一阶自动微分给出静力平衡残差。

## 3. 物理损失

总损失为

```text
L = L_E + L_C + L_B + L_Y.
```

- `L_E`：无体力静力平衡，`d(sigma_xx)/dx + d(sigma_xy)/dy = 0`，`d(sigma_xy)/dx + d(sigma_yy)/dy = 0`。
- `L_C`：网络应力与由位移梯度、初始应力和本构关系得到的应力之间的残差。
- `L_B`：内圆压力、外圆原位压力和两条对称边界残差。
- `L_Y`：`relu(F)^2` 形式的 Mohr-Coulomb 屈服越界惩罚。

对 `P = 8 MPa` 工况，目标解应保持弹性，因此塑性分支不应成为主导机制。`physics.py` 保留共享的 Mohr-Coulomb 本构接口，是原始复现代码的一部分。

## 4. 边界条件

- 内圆 `r=a`：法向压力 `P=8 MPa`，切向牵引为零。
- 外圆 `r=R`：静水压力 `p0=10 MPa`，切向牵引为零。
- `x=0`：法向位移与剪应力为零。
- `y=0`：法向位移与剪应力为零。

## 5. 采样与训练

初始内部点在四分之一圆环中按面积均匀采样。配置写为 300 个内部点和 50 个边界点；由于实现使用四次整数除法 `50//4`，实际边界点为 48 个。

训练先执行 10,000 步 Adam。随后进行 10 轮残差自适应采样：每轮生成 4,000 个候选点，根据平衡残差和本构残差的组合模长进行重要性采样，新增 20 个内部点，再执行 1,000 步 Adam 和一次 L-BFGS 优化。

## 6. 解析解诊断

`plot_deep_elastic_fig10_comparison.py` 使用有限厚圆环的 Lame 弹性解计算 `sigma_r`、`sigma_theta` 和径向位移，并与 PINN 网格预测逐点比较。解析解不参与训练，只用于独立验证。

绘图时应力统一为压应力正值。径向位移使用

```text
u_r = ux cos(theta) + uy sin(theta)
```

并减去外边界平均径向位移，以与原复现的位移参考零点一致。

## 7. 复现边界

该代码是历史纯弹性复现快照，不应被表述为完整的增量 Mohr-Coulomb 塑性积分器。其用途是验证圆形巷道弹性工况下的混合输出 PINN、边界残差、自适应采样和解析解对照流程。
